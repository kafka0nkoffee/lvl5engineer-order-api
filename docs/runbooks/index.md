# Incident Runbooks

Structured response procedures for operational failure scenarios. Two variants exist for each scenario: agent-facing (structured for agent execution with explicit decision trees and named halt conditions) and human-facing (structured for human engineers during incidents).

---

* [Runbook: Payment Gateway Degraded (Agent-Facing)](payment-gateway-degraded-agent.md) — Agent-executable runbook for responding to payment gateway degradation: slow responses, intermittent errors, or timeouts during order processing.
* [Runbook: Payment Gateway Degraded (Human-Facing)](payment-gateway-degraded-human.md) — Human-executable runbook for responding to payment gateway degradation during order processing incidents.
