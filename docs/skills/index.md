# Skills Library

Three-tier skill architecture for the order-api project. Each tier represents a different scope of applicability:

* **Tier 1** — Project-wide standards (apply to all agent output in all contexts)
* **Tier 2** — Domain methodology (apply when working in a specific domain: Gherkin, step definitions, session management)
* **Tier 3** — Personal workflow (apply when producing a specific output type: newsletter findings writing)

Read the applicable skill before producing output in its domain. The Tier 1 skill takes precedence over all other formatting guidance.
