# Tier 2 Skills — Domain Methodology

These skills apply when working in a named domain. Each skill names when to use it and when NOT to use it. Read the "Do NOT use this skill when" section before applying.

---

* [Gherkin Scenario Quality (v2 — Agent-Safe)](gherkin-scenario-quality-v2.md) — Evaluates and produces well-formed Gherkin scenarios using a five-question debt diagnostic, four pre-flight guards, and a minimal-change output contract.
* [Session Start Protocol](session-start-protocol.md) — Initializes a new issue session by creating the findings file, updating the index, and confirming scope before the first tool call.
* [Step Definition Style](step-definition-style.md) — Applies consistent style conventions to pytest-bdd step definitions in tests/steps/, covering naming, scoping, and fixture patterns.
* [Feature File Audit](feature-file-audit.md) — Audits Gherkin feature files for spec debt using a structured debt classification system before major implementation sessions.
* [Gherkin Scenario Quality (v1.1 — deprecated)](gherkin-scenario-quality.md) — Deprecated human-facing Gherkin quality skill superseded by gherkin-scenario-quality-v2.md; preserved as before-state reference for Issue #12.
