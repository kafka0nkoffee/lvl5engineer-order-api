# Tier 1 Skills — Project-Wide Standards

These skills apply to all agent output in all contexts. They are not domain-specific. When any tier-2 or tier-3 skill conflicts with a tier-1 skill on formatting, the tier-1 skill wins.

---

* [Output Formatting Standard](output-formatting-standard.md) — Applies consistent formatting to all agent output: findings files, Gherkin scenarios, commit messages, and code snippets in documentation.
