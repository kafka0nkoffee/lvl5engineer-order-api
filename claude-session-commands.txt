HOW TO ENABLE 99% OF COMMANDS WITHOUT PROMPTING

Claude Code uses a settings.json file to grant permissions. There are two levels:
  - Global:  ~/.claude/settings.json  (applies to all projects)
  - Project: .claude/settings.json    (applies to this project only)

The safest approach: allow read-only operations globally, and allow project-specific
test/script operations at the project level.

--- GLOBAL SETTINGS (~/.claude/settings.json) ---

Add these to allow all read-only shell operations without prompting:

{
  "permissions": {
    "allow": [
      "Bash(find:*)",
      "Bash(ls:*)",
      "Bash(cat:*)",
      "Bash(grep:*)",
      "Bash(which:*)",
      "Bash(echo:*)",
      "Bash(python3 -c *)",
      "Bash(python3 -m pytest*)",
      "Bash(git log*)",
      "Bash(git status*)",
      "Bash(git diff*)",
      "Bash(git show*)",
      "Bash(git stash list*)",
      "Bash(sed -n *)",
      "Bash(head *)",
      "Bash(tail *)",
      "Bash(wc *)",
      "Bash(sort *)",
      "Bash(uniq *)"
    ]
  }
}

--- PROJECT SETTINGS (.claude/settings.json) ---

Add these to allow project-specific operations without prompting:

{
  "permissions": {
    "allow": [
      "Bash(python3 -m pytest*)",
      "Bash(python3 scripts/*)",
      "Bash(.venv/bin/python3*)",
      "Bash(mkdir *)",
      "Bash(pip install*)"
    ]
  }
}

--- WHAT TO KEEP REQUIRING PERMISSION ---

Even with the above in place, the following should always require your explicit
approval. These are the operations that can damage local state, affect shared
systems, or cannot be easily reversed:

  - git commit       → alters history
  - git push         → affects shared remote
  - git reset --hard → potentially destructive
  - git branch -D    → deletes branches
  - rm / rmdir       → deletes files permanently (on macOS without .Trash recovery)
  - kill / pkill     → terminates running processes
  - chmod / chown    → changes file permissions
  - Any command writing to paths outside the project root
  - Any command making real HTTP calls to external services (curl to non-localhost)
  - pip install [new package] (adding NEW packages — updating existing is lower risk)

--- QUICKEST WAY TO SET THIS UP ---

In a Claude Code session, type:

  /allow Bash(find:*), Bash(ls:*), Bash(grep:*), Bash(git log*), Bash(git status*)

Or run the update-config skill to configure settings.json with your preferences.

The goal is: Claude can read anything, run tests, run project scripts, and create
directories — but cannot commit, push, delete, or call external services without
your explicit approval.
